# Security Policy

## Supported Versions

Currently, only the latest version of ASCII Cinema is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security of ASCII Cinema seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them by opening a private vulnerability report on GitHub if available, or by contacting the maintainer directly at `itsmebk2007@gmail.com`.

We will acknowledge your report within 48 hours and provide a timeline for a fix if applicable.
